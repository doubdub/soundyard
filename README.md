# 사운드야드 (SoundYard)

중고 음향기기·악기 거래 사이트 프런트엔드 프로토타입입니다. 빌드 도구 없이 정적 파일 세 개로 동작합니다.

## 실행

```bash
cd soundyard
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. `index.html`을 파일로 직접 열어도 되지만, 로컬 서버로 여는 편이 안전합니다.

## 구성

```
soundyard/
├── index.html          # 페이지 마크업
├── styles.css          # 전체 스타일 (데스크톱 4열 / 모바일 2열)
├── app.js              # 매물 데이터, 필터·정렬, 모달, 로그인, 등록
├── assets/             # 매물 썸네일 SVG 20종
└── tools/
    └── make_assets.py  # 썸네일 SVG 재생성 스크립트 (선택)
```

## 기능

- **카테고리** 16종 + 전체. 데스크톱에서는 두 줄로 펼쳐지고, 좁은 화면에서는 가로 스크롤입니다.
- **검색**: 장비명, 모델명, 브랜드, 지역, 카테고리, 설명을 실시간으로 검색합니다.
- **필터**: 상태(S/A/B급), 거래 방식(직거래/택배)을 다중 선택하고, 최신순·낮은 가격순·높은 가격순으로 정렬합니다.
- **매물 상세**: 스펙, 상태 설명, 시리얼·박스 유무, 거래 지역/방식, 판매자 정보, 조회·찜 수, 찜하기, 채팅 문의.
- **로그인/회원가입**: 이메일 로그인·회원가입, Google/카카오 데모 로그인. 로그인하지 않고 판매하기나 채팅 문의를 누르면 로그인 안내가 뜨고, 로그인 후 원래 동작으로 이어집니다.
- **판매하기**: 카테고리, 제목, 가격, 상태, 거래 방식, 지역, 설명을 입력해 매물을 등록합니다.
- **모바일**: 760px 이하에서 2열 그리드, 헤더 검색창 전체 폭, 모달 바텀시트, 카테고리 가로 스크롤로 전환됩니다.

## 데이터와 저장

기본 매물 20건은 `app.js`의 `SEED` 배열에 들어 있습니다. 가짜 외부 이미지 링크는 쓰지 않고 `assets/`의 로컬 SVG를 사용합니다.

브라우저 저장소(localStorage)에 다음 값을 보관합니다.

| 키 | 내용 |
| --- | --- |
| `sy_user` | 로그인한 사용자 |
| `sy_wishlist` | 찜한 매물 ID 목록 |
| `sy_custom_listings` | 직접 등록한 매물 |

시크릿 창이나 저장소를 비우면 초기 상태(기본 매물 20건)로 돌아갑니다.

## 백엔드 연동 메모

- `SEED`를 API 응답으로 바꾸고 `allListings()`를 서버 조회로 교체하면 목록이 서버 데이터가 됩니다.
- 로그인(`handleLogin`, `handleSignup`, `loginWithProvider`)과 등록(`handleSell`)의 마지막 단계에서 localStorage 대신 API를 호출하면 됩니다.
- 매물 ID는 현재 `sy-001…sy-020`, 직접 등록은 `u-<timestamp>` 형식입니다. 서버 연동 시 실제 ID로 교체하세요.
- 이미지 경로는 `image` 필드 하나로 관리됩니다. 업로드 이미지를 쓰려면 이 필드에 URL을 넣으면 됩니다.

## 참고

- 데모용 인증입니다. 실제 비밀번호 검증이나 소셜 OAuth 연동은 없습니다.
- 채팅 문의는 화면 안에서 전송 완료 토스트만 보여 주고, 실제 메시지는 저장하지 않습니다.
- 매물 등록 시 이미지는 선택한 카테고리의 기본 썸네일이 붙습니다.
